# Northwind Cloud: Fabric Revenue Intelligence Platform

> Status: in progress (Phase 0 done). Built as a client-style engagement on Microsoft Fabric.

## Problem
Leadership gets three different revenue numbers because marketing, sales and finance use separate systems.
This platform ingests marketing, CRM, billing and product telemetry into one governed medallion model
(see [requirements](docs/requirements.md) and [architecture](docs/architecture.md)).
